# Bundled offline map

`world.json` contains country outlines from Natural Earth's public-domain 1:110m Admin 0 dataset, downloaded from:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Properties are reduced to display names, label ranks and label positions; coordinates are rounded to three decimals for bundle size. Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

These generalized outlines provide an offline overview, not road data or precise borders for surveying. Street detail uses the separate online OpenStreetMap tile layer. Borders and names follow the source dataset and do not imply a political position.
